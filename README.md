## Featured project: WA Leads

A WhatsApp lead capture system with a conversational backend and a web dashboard for managing leads and bot settings.

### WA Leads API

The backend captures incoming WhatsApp messages, stores conversations, and guides users through configurable conversation trees.

- WhatsApp Cloud API integration with text, buttons, and lists.
- Support for multiple businesses through tenants, memberships, and roles.
- Supabase authentication and JWT-protected endpoints.
- Incoming message deduplication and optional webhook signature validation per tenant.
- OpenAPI documentation, Docker support, and Render deployment configuration.

**Technologies:** TypeScript, Node.js, Supabase, WhatsApp Cloud API, Docker.

[Explore the API repository](https://github.com/josafatmartinez/wa-leads-api)

### WA Leads Dashboard

The web application provides an interface for reviewing leads, updating their status and notes, and configuring bot messages.

- Next.js dashboard connected to centralized API endpoints.
- Authentication flows for login, signup, invitations, and password reset.
- Protected dashboard pages and server-side session handling.
- Documented Vitest and end-to-end test commands.

**Technologies:** Next.js, React, TypeScript, Supabase, Vitest.

[Explore the dashboard repository](https://github.com/josafatmartinez/wa-leads-saas)
